# AI 圆桌

**English:** A local group chat where Claude, Gemini and GPT take turns and reply to each other, using your own subscriptions through their official command-line tools. You can attach images and documents (PDF, Word, Excel, PowerPoint, text files) to a message. The app follows your system language; switch any time in Settings → 语言 / Language. This guide is in Chinese for now.

把 Claude、Gemini、GPT 拉进同一个群聊：你出题，它们轮流发言、互相接话。程序完全在你自己的电脑上运行。

| 成员 | 默认接入方式 | 用的是 |
|---|---|---|
| Claude | Claude Code 命令行（`claude`） | 你的 Claude Max 订阅 |
| Gemini | Antigravity CLI 命令行（`agy`） | 你的 Google AI Pro 订阅 |
| GPT | Codex CLI 命令行（`codex`） | 你的 ChatGPT 账号，免费账号也能用（不需要 ChatGPT 订阅） |

## 一、安装 AI 圆桌

1. 下载安装包 `AI-Roundtable-Setup-x.y.z.exe`，两个地方都可以：
   - 本仓库的 **[Releases 页面](https://github.com/hulkbai-beep/ai-roundtable/releases)**（发布过的正式版本）；
   - 仓库的 **[Actions 页面](https://github.com/hulkbai-beep/ai-roundtable/actions)** → 最近一次带绿色勾的「测试和打包」→ 页面底部 Artifacts 里的 `AI-Roundtable-Windows`。下载下来是一个 zip，解压出来就是安装包。每次改代码都会自动生成，保留 90 天。
2. 双击安装。安装包没有做代码签名，Windows 可能弹出“Windows 已保护你的电脑”，点「更多信息」→「仍要运行」。
3. 装好后，开始菜单和桌面上会有 **AI 圆桌** 的图标。

## 二、准备三位成员（只需要做一次）

### 1. Claude：安装并登录 Claude Code

已经在用 Claude Code 的话可以跳过。打开 PowerShell，运行：

```powershell
irm https://claude.ai/install.ps1 | iex
```

装好后运行一次 `claude`，按提示用 **Max 账号**登录。登录成功后输入 `/exit` 退出。

### 2. Gemini：安装并登录 Antigravity CLI

> 2026 年 6 月 18 日起，Gemini CLI 不能再用 AI Pro 订阅登录，订阅用户需要改用 Google 的 Antigravity CLI（命令叫 `agy`）。

在 PowerShell 里运行下面任意一个（安装方式以 Google 官方页面为准）：

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

```powershell
winget install Google.AntigravityCLI
```

装好后运行一次 `agy`，用**开通了 AI Pro 的 Google 账号**登录，然后退出。

### 3. GPT：安装并登录 Codex CLI（免费）

先在 PowerShell 里检查一下是不是已经装过：

```powershell
where.exe codex
```

能看到类似 `C:\Users\你的用户名\AppData\Roaming\npm\codex.cmd` 的路径，就说明装好了，跳到最后一步登录。没装的话，先安装 Node.js（https://nodejs.org 下载 LTS 版），再运行：

```powershell
npm i -g @openai/codex
```

最后运行一次 `codex`，选择用 **ChatGPT 账号**登录（免费账号也可以），登录成功后退出。

> OpenAI 目前允许免费的 ChatGPT 账号使用 Codex，但额度比较小，也可能只是限时开放。哪天用不了了，可以把 GPT 换成「GitHub Models」，同样免费，步骤见下面「常见问题」。

## 三、第一次设置

1. 打开 AI 圆桌，点右上角的齿轮「设置」。

## 四、怎么玩

- **模式**
  - 自由讨论：像朋友聊天，可以有分歧
  - 辩论：各自亮明立场，互相反驳
  - 合作：一起完成一个任务，最后一位会总结
  - 各自回答：三位同时回答，这一轮互相看不到对方的回答，适合对比三家（用量和轮流回答一样，只需要等最慢的那一位）
- **轮数**：每位成员发言几次。选 2 轮以上，它们会回应彼此的观点。
- **篇幅**：简短 / 适中 / 详细
- **发言顺序**：自由讨论和辩论时大家轮流发言，后说的人能看到前面的发言。每条消息会换一个发言顺序，免得总是同一位先说、同一位压轴；想固定顺序的话，在设置里关掉「每条消息换一个发言顺序」，就按设置里排的顺序来。合作模式始终按设置里排的顺序。
- **@点名**：消息里写 `@Claude`、`@Gemini`、`@GPT`，只有被点到的成员回答；`@所有人` 表示全员。点了两位以上时，按你点名的顺序一个一个回答，后面的能看到前面的回答（比如“@GPT 先写，@Claude 来改”）。
- **发图片和文件**：点输入框旁边的回形针，或者把文件拖进窗口、直接粘贴截图。支持图片（PNG、JPG、GIF、WebP）、PDF、Word / Excel / PowerPoint（docx、xlsx、pptx）和各种纯文本文件（txt、md、csv、json、代码等）；每个文件最大 15 MB，一条消息最多 10 个。文档里的文字是在你自己的电脑上取出来的，和聊天记录一起发给每位成员，所以三位都能看到内容。图片和取不出文字的 PDF（扫描件）会把文件本身交给各位成员，对方要能“看图”才行，见下面的常见问题。成员说的「附件 1」「附件 2」，是按你发出的先后顺序编的号。
- **上网搜索**：默认打开。问到最新的消息、或者你在消息里给了网址时，成员会自己去搜索、打开网页，并在回复里给出来源；用不着查的问题照常直接回答。查的时候回复会慢一些，也多耗一些额度。不想让它们上网，在设置里关掉「让成员上网搜索」。哪些接入方式支持，见下面的常见问题。
- **继续聊**：不发新消息，让大家再聊一轮。
- **停止**：打断正在发言的成员（同时回答时是所有正在回答的成员），取消后面排队的发言。
- 它们说话的时候你也可以插话：新消息会被后面发言的成员看到，并替换掉还没轮到的发言安排。
- 右上角按钮：历史对话、用量、导出 Markdown、新对话、设置。
- 每次打开 AI 圆桌都从一个新的空对话开始；上次的对话自动存进「历史对话」，点开就能接着聊（一句话没说的空对话不会存）。
- **用量和额度用完**：每条回复旁边会标出这次用了多少 token；右上角「用量」里能看到每位成员最近 5 小时、24 小时、7 天的用量（合计 = 输入 + 输出；带 * 的另有走缓存的输入，它便宜得多，没有算进合计。Claude Code、Codex 和各种接口用的是工具报告的数字；Antigravity CLI 不报告用量，前面带 ≈ 的是按字数估算的）。某位成员的额度用完时，AI 圆桌会响一声，在顶部和聊天里提醒你、把它标成「额度用完」，接下来的发言先跳过它，由其他成员继续聊。读得出恢复时间的话，到时间它会自动回到群里；读不出的话一小时后自动再试（只是请求太频繁的话，过五分钟就再试）。你也可以用 @点名、「保存并测试」或「用量」里的「再试一次」马上再试。把这位成员换成另一种接入方式（比如 GPT 从 Codex 换成 GitHub Models），或者改了它的接入设置（比如换了模型或 Key），也能马上继续。
- 每位成员可以在设置里选 **模型** 和 **思考强度**（低 / 中 / 高……）。思考强度越高，回复越慢、越耗额度。每条回复旁边会标出用的模型和思考强度。
- 界面有中文和英文两种语言：默认跟随系统，也可以在设置的「语言 / Language」里切换。切到英文后，AI 默认也用英文回复。
- 设置里还可以：调整排好的发言顺序、暂时关掉某位成员、给某位加「额外人设」（比如“你是一位挑剔的投资人”）。

## 五、常见问题

**某位成员测试失败？** 先看红字里的“建议”。常见原因：

- **找不到命令**：刚装完的话，关掉 AI 圆桌再重新打开；还不行就在设置里填 `.exe` 的完整路径（比如 `C:\Users\你的用户名\.local\bin\claude.exe`）。
- **Claude 提示登录 / 认证问题**：在 PowerShell 里运行一次 `claude` 重新登录。
- **Gemini（agy）没有输出或者一直超时**：有用户反馈 agy 被别的程序调用时可能卡住。先确认 agy 是最新版本；还不行的话，在设置里把 Gemini 的接入方式换成「Gemini API Key」。这需要在 Google AI Studio（https://aistudio.google.com）申请 API Key，而且**不走 AI Pro 订阅**，费用和免费额度以官网为准。
- **GPT（Codex）提示登录问题**：在 PowerShell 里运行一次 `codex` 重新登录。**提示额度用完**：免费账号的额度比较小，过一阵再试，或者暂时换成 GitHub Models。
- **Codex 回复比较慢**：在设置里把 GPT 的「思考强度」选成「低」，让它少想一点、回复快一些。

**发了图片或文件，有成员说看不到？** 文档里的文字每位成员都能看到；图片和扫描的 PDF 要看各家怎么接收文件：

| 成员（接入方式） | 图片、扫描的 PDF 是怎么交给它的 |
|---|---|
| Claude（Claude Code） | 它自己打开文件来看。带附件的那几次发言会临时打开“读文件”这个工具，并且指明用 Claude Code 的“默认”权限模式（不跟着你自己在 Claude Code 里设的自动模式、跳过确认模式走）。这个模式下它只能读运行目录（也就是保存附件的地方）里的文件，读别处会被拒绝，除非你自己在 Claude Code 的设置里另外写了允许的规则。超过 10 页的 PDF，Claude Code 要借助 poppler 的 `pdftoppm` 才能看：Windows 上需要自己装一个 poppler 并把它加进 PATH，没装的话这样的 PDF 它读不了 |
| GPT（Codex CLI） | 图片直接附在消息里；PDF 由它自己打开 |
| Gemini（Antigravity CLI） | 只能告诉它文件在哪、让它自己打开。**这一种还没有在真机上验证过**，它看不到的话，把接入方式换成「Gemini API Key」 |
| Gemini API Key | 随请求一起发过去 |
| GitHub Models、自定义接口 | 随请求一起发过去。模型不收 PDF 或图片时，AI 圆桌会去掉它们再发一次，并在那条回复下面注明哪个附件没发过去 |

另外几种情况：

- **文档很长**：每位成员一次发言能带的字数有限（设置里显示高级选项后的「最多带多少字的聊天记录」，附件最多占一半）。放不下时只带开头，回复下面会注明“只发了开头多少字”。Claude Code 和 Codex 会自己去读完整的文字，其他成员可以把这个上限调大，或者把文档拆小了再发。特别长的文档最多读出开头的 40 万字，附件上会标「不完整」。
- **PDF 显示“读不出文字”**：多半是扫描件，或者加了密码。这时只有能直接看 PDF 的成员看得到内容。加了密码的，各位成员多半也打不开，先去掉密码（另存或者打印成一份新的 PDF）再发。
- **PDF 里有的页是扫描的图片**：这些页在读出来的文字里会标成“（图片，没有能读出来的文字）”。图片页占到五分之一时，附件上标「不完整」，文件本身也会交给各位成员（见上表）。
- **Word / Excel / PowerPoint 里会读哪些内容**：除了正文，Word 的脚注、尾注、批注、页眉页脚，PowerPoint 的演讲者备注，还有隐藏的工作表和隐藏的幻灯片（会标明“隐藏”）都会读出来、发给各位成员。不想让成员看到的内容，发之前先从文件里删掉。嵌在文档里的图片和图表不会读。
- **希伯来文、阿拉伯文的 PDF**：文字会转回阅读的顺序，但分开画的元音符号可能落在相邻的字母上。
- **旧格式的 .doc / .xls / .ppt**：读不了。用 Word / Excel / PowerPoint 另存为 .docx / .xlsx / .pptx 或 PDF 再发。
- **文本文件变成乱码**：能自动识别 UTF-8、UTF-16、GBK（GB18030）和西欧语言的 Windows-1252。其他编码（比如繁体中文的 Big5、日文的 Shift_JIS）认不出来，请先另存为 UTF-8。
- **附件很多**：一次发言最多带最近的 8 个图片 / PDF 文件，更早的只告诉成员文件名。聊得很长、附件特别多时，最早的那些不再列出，回复下面会注明。

**连不上 GitHub / Google 的接口？** 如果你平时要开代理（比如 Clash），在设置里填代理地址，例如 `http://127.0.0.1:7890`。

**每条 Claude 回复都会触发我给 Claude Code 配的 hooks（比如提示音）？** 在设置里勾选「显示高级选项」，在 Claude 的「额外命令行参数」里填 `--safe-mode`。

**想换一种方式接 GPT？** 设置里 GPT 的接入方式还可以选：

- **GitHub Models（免费）**：用 GitHub 账号自带的免费额度。
  1. 打开 https://github.com/settings/personal-access-tokens/new （Fine-grained token），Token name 随便填，选一个有效期。
  2. 在权限（Permissions）里找到 **Models**，设为 **Read-only**，点 Generate token。
  3. 把以 `github_pat_` 开头的 token 粘贴到设置里 GPT 卡片的「GitHub Token」，点「保存并测试」。

  免费额度大约每天几十到一百多次请求，每次请求最多约 8000 token。报 401 是 token 不对或过期，403 是没给 Models 权限，429 是今天的额度用完了。
- **自定义 OpenAI 兼容接口**：比如 OpenRouter，或者本机 Ollama 跑的开源模型（接口地址 `http://localhost:11434/v1`）。

**成员能上网查东西吗？** 能，设置里的「让成员上网搜索」默认是打开的，各家用的是自己带的搜索：

| 成员 | 怎么上网 |
| --- | --- |
| Claude（Claude Code） | 打开它的“搜索”和“打开网页”两个工具，别的工具还是关着的。 |
| GPT（Codex） | 用 Codex 自带的网页搜索（由 OpenAI 那边去搜），它在你电脑上仍然是只读模式。 |
| Gemini（Antigravity CLI） | 它自带搜索和读网页的工具，AI 圆桌只是告诉它可以用。 |
| Gemini（API Key） | 在请求里打开 Google 搜索和读网址。**用付费的 Key 时，Google 可能按搜索次数另外收费**；模型不支持或者搜索的额度用完时，会照常回答并在回复旁边注明。 |
| GPT（GitHub Models、自定义接口） | 不支持，这两种接入方式没有通用的搜索办法。 |

某位成员说自己上不了网，多半是命令行工具的版本太旧，或者你（或公司）在它自己的设置里禁用了上网的工具：先把工具更新到最新版本。这个功能是照着各家的官方文档做的，还没有在真实账号上逐个验证过；如果不好用，点设置左下角的「保存诊断信息」把文件发给开发者。

**额度怎么算？** 每次发言都会把聊天记录发给对应的 AI，聊得越久越耗额度。Claude 和 Gemini 用的是你的订阅额度，和你平时在网页、App 上的用量是同一份。轮数开得越多，消耗越快。各家订阅的具体额度官方没有公开，所以「用量」里只统计在 AI 圆桌里用了多少，「额度用完」是根据工具的报错判断的。

**出了问题想看日志？** 菜单「文件」→「打开日志」（按 Alt 键显示菜单）。把日志里的报错发给开发者就行。

**某位成员总是出错、想让开发者帮忙看？** 打开设置，点左下角的「保存诊断信息」，把保存下来的 `.md` 文件发给开发者。里面有各个命令行工具的版本，以及最近 30 次发言（包括「保存并测试」）里每个工具是怎么启动的、原样输出了什么。API Key、Token 和代理的账号密码不会写进去，但**里面有最近聊天的部分内容**，发之前先自己看一遍。

## 六、数据和隐私

- 程序只在你的电脑上运行，只接受本机（127.0.0.1）的访问，局域网里的其他设备连不上。
- 设置、聊天记录和日志保存在 `%APPDATA%\AI Roundtable`（菜单「文件」→「打开数据文件夹」）。API Key、Token 等设置保存在其中的 `config.json`（明文），不要发给别人。卸载程序时这些数据会保留。
- 三个命令行工具都在数据目录里的 `workspace` 文件夹里运行，里面只有你发过的附件（`workspace\attachments`）。Claude 只打开用得着的工具：带着附件发言时打开“读文件”（指明用默认权限模式，只能读这个文件夹里的文件），打开了「让成员上网搜索」时打开“搜索”和“打开网页”，其余的都关着；Codex 是只读模式。另外也会要求它们只聊天、除了上网和看附件不读写别的文件、不运行命令。
- 打开「让成员上网搜索」（默认打开）时，成员会把要查的内容发给各家的搜索服务，也会打开搜到的或者你给的网页。网页是别人写的，里面可能藏着写给 AI 的话（比如“忽略前面的要求”）：AI 圆桌会提醒成员把网页上的文字只当资料看，但这类提醒不是百分之百管用。聊的内容比较敏感、不想让任何一部分被拿去搜索时，先在设置里把它关掉。
- 为了出问题时能查，最近 30 次发言里各个工具的原样输出保存在数据目录的 `diagnostics.json`（里面有聊天的部分内容，更早的会自动删掉）。它只留在你的电脑上；只有你点「保存诊断信息」、再把保存下来的文件发出去，别人才看得到。
- 你发的图片和文件保存在 `workspace\attachments`，和聊天记录一样一直留着（打开历史对话时还能看到）；选了但没发出去的，关闭程序时会删掉。文档的文字是在本机取出来的（包括批注、备注、隐藏的工作表和幻灯片）；附件的内容只会发给参加群聊的那几家 AI。

## 七、开发者说明

| 路径 | 作用 |
|---|---|
| `electron/main.js` | 桌面版入口：启动本地服务，在窗口里显示界面 |
| `server.js`、`start.bat` | 浏览器版入口：不装桌面版也能用（需要 Node.js 18+） |
| `lib/` | 后台：调度谁发言（`orchestrator.js`）、三家的接入方式（`providers.js`）、Windows 上启动命令行工具（`spawn.js`）、用量和额度（`usage.js`、`limits.js`） |
| `lib/prompt.js` | 群聊规则（AI 的“人设”），想调整说话风格改这里 |
| `lib/attachments.js`、`lib/doc-text.js`、`lib/pdf-text.js` | 附件：判断文件类型、保存，从 Word / Excel / PowerPoint / PDF / 文本文件里取出文字（自己解析，不依赖第三方库） |
| `public/` | 网页界面，桌面版和浏览器版共用 |
| `test/` | 自动测试，用模拟的命令行工具和接口，不会真的调用 AI。`test/fixtures/` 里是真实软件生成的样本文档 |

```bash
npm install            # 安装开发依赖（Electron 和打包工具）
npm start              # 浏览器版
npm run app            # 桌面版（开发模式）
npm test               # 自动测试
npm run dist:win       # 打包 Windows 安装包（需要在 Windows 上运行）
```

每次推送到 `main`，GitHub Actions 会在 Linux 和 Windows 上跑测试，再在 Windows 上打包安装包并测试打包结果。

**发布一个正式版本：** 打开仓库的 Actions 页面 → 左边选「测试和打包」→ 右边点「Run workflow」→ 在「要发布的版本号」里填比如 `1.0.0` → 点绿色的「Run workflow」。大约 10 分钟后，Releases 页面就会出现 `v1.0.0`，里面附带安装包。（推送 `v` 开头的标签也能触发发布。）
